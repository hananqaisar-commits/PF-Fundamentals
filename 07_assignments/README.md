# Assignments and Labs

First-semester submitted work and labs: healthcare profiles, a character diamond, the Twelve Days song, a math quiz, and student marks processing.

## Files

- `healthcare_profile.c` — patient profile, age, heart-rate, and BMI calculations.
- `character_diamond.c` — diamond pattern using a chosen character.
- `twelve_days_song.c` — Twelve Days of Christmas text using `switch`.
- `math_quiz_lab.c` — random-answer math quiz.
- `student_marks_lab.c` — student marks and averages.
