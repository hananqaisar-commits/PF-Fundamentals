# Patterns

Nested-loop pattern programs: checkerboard, triangles, hollow squares, pyramids, and diamonds.

Each file prints one pattern in the terminal.

## Files

- `05_checkerboard_pattern.c` — alternating checkerboard grid.
- `25_pattern_left_triangle.c` and `26_pattern_inverted_triangle.c` — left-aligned triangles.
- `27_pattern_hollow_square.c` — hollow square.
- `28_pattern_right_spaced_triangle.c` and `29_pattern_right_solid_triangle.c` — right-aligned triangles.
- `30_pattern_diamond_pyramid.c` and `31_pattern_full_diamond.c` — diamond patterns.

### Extracted unit practice

Files beginning with `unit_02_`, `unit_03_`, and `unit_04_` are complete pattern exercises recovered from the commented unit notes.
