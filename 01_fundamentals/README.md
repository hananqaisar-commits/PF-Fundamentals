# Fundamentals

Introductory C exercises covering input/output, decisions, loops, arithmetic, basic patterns, and small business calculations. Files retain their original exercise numbers where available.

Compile any file with `gcc file_name.c -o program` and run it with `./program`.

## Files

- `01_factorial.c` — factorial of a number.
- `01_functions_collection.c` — collection of basic function exercises.
- `02_prime_number_check.c` — prime-number test.
- `03_n_asterisks_grid.c` and `04_hollow_square.c` — introductory loop patterns.
- `06_circle_diameter_circumference.c` — circle measurements.
- `07_reverse_5digit_manual.c` and `08_palindrome_check.c` — number reversal and palindrome logic.
- `09_triangle_validity.c` and `10_right_angle_triangle_check.c` — triangle checks.
- `11_sum_of_sequence.c`, `12_sum_of_even_numbers.c`, and `13_product_of_odd_numbers.c` — loop calculations.
- `14_compound_interest_table.c` and `15_compound_interest_multirate.c` — interest calculations.
- `16_fuel_efficiency_calculator.c` through `24_employee_salary_tax.c` — finance, payroll, sales, and employee exercises.
- `25_temperature_converter.c` — temperature conversion.
- `32_star_bar_chart.c` and `33_airline_seat_booking.c` — a bar chart and airline seat booking exercise.

### Extracted unit practice

The `unit_02_*`, `unit_03_*`, and `unit_04_*` files were recovered from complete commented programs in the original unit notes. They preserve early versions of factorial, prime, geometry, finance, and loop exercises.
