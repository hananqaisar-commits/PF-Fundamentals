## ⚙️ How to Compile & Run

```bash
gcc filename.c -o output
./output
```

For programs using `pow()` or `sqrt()` (math.h):
```bash
gcc filename.c -o output -lm
./output
```

Example:
```bash
gcc 01_factorial.c -o factorial
./factorial
```
