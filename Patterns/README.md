# C Pattern Programs ⭐

A collection of C pattern programs using nested loops — great for beginners learning loop logic and pattern building.

---

## 📋 Patterns List

| # | File | Pattern Name | Description |
|---|------|-------------|-------------|
| 01 | `05_checkerboard_pattern.c` | Checkerboard Pattern | 8x8 alternating star grid |
| 02 | `25_pattern_left_triangle.c` | Left Aligned Star Triangle | Grows from 1 star to n stars |
| 03 | `26_pattern_inverted_triangle.c` | Inverted Star Triangle | Shrinks from n stars to 1 star |
| 04 | `27_pattern_hollow_square.c` | Hollow Square | Prints a hollow square border |
| 05 | `28_pattern_right_spaced_triangle.c` | Right Spaced Triangle | Stars with spaces, right aligned |
| 06 | `29_pattern_right_solid_triangle.c` | Right Solid Triangle | Solid stars, right aligned |
| 07 | `30_pattern_diamond_pyramid.c` | Diamond Pyramid | Centered growing star pyramid |
| 08 | `31_pattern_full_diamond.c` | Full Diamond | Complete diamond top + bottom |

## ⚙️ How to Compile & Run

```bash

./output
```

```bash

./pattern
```
