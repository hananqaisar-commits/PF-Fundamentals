# Recursion

Recursive programs for factorials, palindrome checks, reversing arrays, and the Tower of Hanoi, plus a general recursion practice file.

## Files

- `factorial_and_power.c` — factorial and integer-power functions.
- `palindrome_check.c` — recursive palindrome check.
- `recursion_basics.c` — factorial, counting, and greeting recursion practice.
- `reverse_arrays.c` — iterative and recursive array reversal.
- `tower_of_hanoi.c` — classic Tower of Hanoi solution.
