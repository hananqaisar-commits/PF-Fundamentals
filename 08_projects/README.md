# Projects

Larger console exercises, including a billing system, Tic-Tac-Toe versions, a hare-and-tortoise race simulation, and a student pass/fail report.

## Files

- `billing_system.c` — item quantities, prices, totals, and discount calculation.
- `hare_and_tortoise_race.c` — random-movement race simulation.
- `student_pass_fail_report.c` — class marks and pass/fail reporting.
- `tic_tac_toe.c` and `tic_tac_toe_variant.c` — two versions of a terminal Tic-Tac-Toe game.
- `unit_04_billing_system.c` — the original Unit 4 billing-system program.
- `unit_06_airline_seat_assignment.c` — airline-seat assignment with passenger records.
