# Pointers

Pointer fundamentals and practice programs, including swapping values, finding a maximum, returning values through pointers, and modifying arrays through function parameters.

## Files

- `pointers_intro.c` — basic addresses and pointer variables.
- `max_number_by_pointers.c` — compares two values through pointers.
- `pointer_multiple_results.c` — returns sum, product, and average through pointer parameters.
- `modify_array_with_pointers.c` — passes an array to a function for modification.
- `pointer_practice.c` — pointer and array-reversal exercises.
- `swap_numbers.c` — value swapping practice.
