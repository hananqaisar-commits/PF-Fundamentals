# Arrays and Searching

Exercises on array traversal, duplicate frequencies, merging arrays, bubble sorting, largest and second-largest values, two-sum pairs, and linear/binary search.

Start with `bubble_sort_arrays.c` or `sorting_and_binary_search.c` for sorting practice.

## Files

- `array_value_frequency.c` — counts how often values appear.
- `array_sorting_and_methods.c` — sorting and helper methods on an array.
- `bubble_sort_arrays.c` — bubble-sort practice.
- `largest_element_with_pointer.c` — finds the largest element using a pointer.
- `linear_and_binary_search.c` and `sorting_and_binary_search.c` — search algorithm practice.
- `merge_arrays.c` — combines two arrays.
- `second_largest_element.c` — finds the largest and second-largest values.
- `two_sum_pairs.c` — finds pairs whose sum matches a target.
